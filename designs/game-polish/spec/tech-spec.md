# 技术 Spec — 拼个帅哥美女 · 从 HTML 试玩到小游戏

## 1. 背景与目标

现网（GitHub Pages，`index.html?v=22`）功能已通：方形/异形关卡、托盘在棋盘下、本地图只玩不存、金币+广告换提示、通关卡已重画过一轮。对标 Yateland / 旅者拼图 / 宝宝拼图时，差距不在「少一个功能」，而在**没有当成一款游戏做完**：五套配色、扁平块、网页 HUD、振荡器音效、图集成色不齐。

成功看起来像：同一盏台灯下的木桌拼图；块有厚度和咬合；对局界面几乎只有图和手；通关像揭开一张照片而不是弹出网页；图库像一本精选杂志而不是素材文件夹。载体仍是 HTML，标准按小游戏。

## 2. 范围

### In（必须全部做完，不按最短路径裁）

| 编号 | 工作流 | 要做成什么 |
|---|---|---|
| W0 | 美术宪法 | 锁死「桌面实体拼图」世界：色板、字体、间距、材质、文案语气 |
| W1 | 全屏同一世界 | 开屏/首页/图库/对局/通关/我的/底栏 共用 token，去掉网页感 chrome |
| W2 | 棋盘材质 | 木纹或毡面实贴图、内倒角画框、方形浅刻线；异形无网格 |
| W3 | 拼图块材质 | 斜面高光+底影、纸厚、接缝、锁定后齐平；去掉廉价白边 |
| W4 | 对局 HUD 做减法 | 钱包出对局；工具收入「更多」；进度极简；裁定条不常驻 |
| W5 | 手感动效 | 发牌、抬起、磁吸、落子、拒收、连击、碎裂、屏间转场 |
| W6 | 拟音 | 短采样（拾起/放下/咬合/错放/通关）；音效与可选 BGM 分开关 |
| W7 | 通关仪式 | 单关揭照 + 六关全通更大仪式，与世界同一材质 |
| W8 | 内容成色 | 精选主库、统一裁切与调色、封面方向一致；淘汰废图 |
| W9 | 首局与生产态 | 首次点按开声、加载/失败/空图库、刘海安全区、文案去试玩 |
| W10 | 经济与提示的时间感 | 金币飞入、广告换提示的等待与兑现，像游戏奖励不像后台 toast |
| W11 | 设备与性能 | 中端机 60fps 目标、iOS 静音说明、缓存版本、真机清单 |

### Out

- 不换 Unity / Pixi / React；本轮不引入打包器。
- 不做第二款百科 App、不做儿童版、不做内购、不做账号云存档。
- 不恢复异形网格；不改「先拼边框」规则（异形仍靠预锁角）。
- 不把本地图写入图库或上传服务器。
- 不为「看起来高级」加假广告条、假商城、假社交。

## 3. 方案概述

### 主路径

1. **先锁世界（W0）**：写 CSS 自定义属性 + 短美术说明（色、木纹、纸、灯光方向固定左上）。所有后续画面只引用 token，禁止再发明一套紫/绿/蜜桃。
2. **外壳（W1, W4, W9）**：从开屏到「我的」按同一外壳重排。对局页只留棋盘、托盘、一行极简状态、一个菜单钮。
3. **物体（W2, W3）**：棋盘与块改为「贴图 + 多层阴影 + 斜面」，方形与异形两套几何共用同一光照方向。
4. **时间（W5, W6, W7, W10）**：每个玩家动作有 80–220ms 的物理反馈；通关 1.2–2.5s 仪式；禁止无声无动画的状态跳变。
5. **内容（W8）**：主推美女/帅哥（可保留二次元/地标/车为「更多」），但**全部过同一道选图与调色门**，宁少勿滥。
6. **收口（W11）**：真机过关、打缓存、对照 §8 勾选。

### 关键取舍

| 议题 | 选项 | 决定 | 原因 |
|---|---|---|---|
| 视觉世界 | 夜店霓虹 vs 儿童粉彩 vs 木桌实体拼图 | **木桌实体拼图** | 成人题材、对标实体玩具与旅行拼图，而不是 H5 运营页或宝宝 App |
| 块的实现 | Canvas 重绘 vs DOM+CSS | **继续 DOM**，用贴图/伪元素/滤镜做斜面 | 现有拖拽与 `clip-path` 异形已通；换 Canvas 等于重写交互，本轮禁止换栈 |
| 音效 | 继续振荡器 vs 短 WAV/OGG | **短采样为主**，振荡器仅作无文件时的回退且默认不对外 | 复盘已证振荡器即使用压缩器仍像「网页提示音」 |
| 图集规模 | 每类 20 张全留 vs 精选 | **主库精选（每主类约 12–16 张过线）**，其余进备选或删除 | 成色比数量更接近「一款游戏」；废图会瞬间打回试玩感 |
| 灯光 | 每屏自定 | **全局左上主光** | 块高光、棋盘内阴、按钮浮起必须同一方向才像物体 |

推荐 token（实现时写入 `:root`，数值可微调用具校对）：

- 桌面 `#3A2A1E` / 毡面或木纹贴图叠加
- 纸 `#F4EFE6` / 墨 `#2B241C`
- 强调（仅 CTA） `#C45C26`
- 成功 `#3F6B4E` / 错误反馈用短震动+声，不用常驻红框
- 展示字体：现有得意黑（Smiley Sans）；正文：系统 UI 宋/黑体，**禁止第三套装饰字体**
- 间距：8px 网格

## 4. 触点

### UI / 入口

| 入口 | 行为 | 状态 |
|---|---|---|
| 开屏 | 标题序列：散落块合拢或静帧揭题 → 唯一 CTA「开拼」 | 加载字体+首屏图；无假广告条；无「个人版」 |
| 首页 | 一张封面级大图 + 今日推荐 + 开拼；次要入口弱化 | 图加载中骨架；失败可重试 |
| 图库 | 大缩略图、统一画框、分类少而清；本地点按即玩 | 空分类说明；本地无图时引导系统相册 |
| 对局 | 棋盘+托盘+菜单；进度点或「已拼 n/N」 | 发牌中不可操作；暂停菜单含音效/音乐/放弃 |
| 通关 | 揭照 + 短句 + 下一关/回图库 | 单关 / 六关全通两套强度 |
| 我的 | 当暂停室：金币、提示次数、音画开关、关于 | 不是系统设置页堆砌 |
| 底栏 | 最多 3–4 项，图标与填色跟世界走 | 对局中可隐藏或降为返回 |

### 事件（前端，无后端 API）

| 事件 | 反馈 |
|---|---|
| pointerdown 首次 | 解锁 AudioContext；若失败，设置里可再点「开启声音」 |
| 拾起块 | 抬起 4–8px、影变长、轻「纸」声 |
| 靠近正确槽 | 磁吸预览（位移动画，不是闪框） |
| 锁定 | 落平、短咬合声、微量粒子（每块，可限流） |
| 放错 | 弹回托盘或轻拒，无刺耳音、无常驻红框 |
| 连击 | 已有 combo 声加强，加极短屏幕震动（CSS） |
| 通关 | 碎裂或揭照 → 结果卡 |
| 看广告换提示 | 等待态 → 成功兑现动画 → 预锁/高亮生效 |
| 金币入账 | 角标数字跳动，不挡棋盘 |

### API

无。静态站 + `localStorage` + 可选广告 SDK 位（已有占位则只修体验，不新接账号）。

## 5. 数据变更

- 无服务端表。
- `manmanpin_v1` 可**增量**字段：`musicOn`、`sfxOn` 分离、`artPack` 版本、`seenTitle`（是否跳过开屏动画）。缺省按旧键迁移，禁止清档。
- 图集清单仍在 `catalog.js` / `CAT_PINNED`；删图要同步清单与 `assets/`，避免 404。

## 6. 权限与安全

- 本地相册：仅 File API 读入内存，禁止 `dataURL` 写入 collection / localStorage。
- 外链图若仍有，须可失败降级；本轮目标是主库全本地。
- 不收集人脸、不上传用户图。

## 7. 失败与回滚

- CSS/贴图失败：棋盘仍可玩（纯色桌面回退），但 **QA 视为未过线**，须补资源。
- 采样音频解码失败：静音可玩，设置页提示；不得再把振荡器当正式方案对外吹。
- 单次发布用 `?v=` 递增；回滚即回上一版静态文件。
- 清档不是回滚手段。

## 8. 验收（可证伪）

对照物：Yateland / 旅者拼图 / 旅行类完成页——不是「比上一版 HTML 好看」。

### 世界

- [ ] 开屏、首页、图库、对局、通关、我的，截图并排时能看出是同一产品（同一木色、同一字体、同一主光）。
- [ ] 全文搜不到「个人版」「试玩」「广告位」等网页占位文案。
- [ ] 底栏、顶栏、按钮、卡片半径与描边来自同一套 token。

### 物体

- [ ] 棋盘能看出材质（木或毡），不是 CSS 纯色+粗框。
- [ ] 方形块无 1px 白描边作为主轮廓；斜面高光在左上，阴影在右下。
- [ ] 异形块齿与槽在锁定后接缝可接受（允许微缝，不允许「贴纸浮在网上」）。
- [ ] 幽灵底图是「印在板上的淡图」，不是半透明网页水印乱闪。

### 手与时间

- [ ] 拾起/放下/咬合/错放四段都有动画+音（静音开关关闭时只留动画）。
- [ ] 通关不是白底 sheet；单关与六关全通可区分。
- [ ] 从首页进对局、通关回图库，有过渡，不是 display 硬切。

### 内容

- [ ] 主库每张图：人物完整、裁切一致、无明显 AI 残肢/乱纹/水印；不过线的已下架。
- [ ] 封面图与局内图一致（不再「封面一张、进去另一张」除非有意的揭晓）。

### 生产

- [ ] 首点有声（或明确引导点一次）；iPhone 硬件静音时设置页有一句说明。
- [ ] 图未加载完有骨架；加载失败可重试。
- [ ] 刘海/底部手势条不挡托盘与底栏。
- [ ] 6×6 拖拽在目标真机上可玩，无明显掉帧。

## 9. 开放问题

| 问题 | 默认 | 谁定 |
|---|---|---|
| 桌面用木纹还是深色毡 | **木纹**（更像实体拼图盒） | 用户若否决，改毡，不改其它原则 |
| 主库最终张数 | 美女 12–16 + 帅哥 12–16；其它类各 ≤10 张过线 | 实现 W8 时按过线标准裁，不追求凑 20 |
| 是否要极弱循环 BGM | **要**，默认关，设置里开；音量远低于音效 | 用户可一句去掉 |
| 通关揭照用碎裂还是翻页 | **保留碎裂**，结果卡改材质与排版 | 已有碎裂资产，避免再换一套无意义仪式 |
| 广告 SDK 真接还是继续占位 | 本轮只做**等待与兑现体验**；真广告密钥不进规格 | 用户另开一轮 |

未知且会改架构的项：无。DOM 拼图方案已锁。
