# 美术宪法 — 桌面实体拼图

一页锁死。实现只引用，不另起主题。

## 世界
台灯下的木桌。人像是杂志级照片，壳是木头和纸，不是运营 H5。

## 色
| Token | 值 | 用途 |
|---|---|---|
| `--desk` | `#3A2A1E` | 桌面、顶栏、对局台面 |
| `--desk-deep` | `#2A1C14` | 页外底、开屏、深槽 |
| `--paper` | `#F4EFE6` | 内容区、卡片、通关卡 |
| `--ink` | `#2B241C` | 正文 |
| `--muted` | `#7A7064` | 辅助 |
| `--accent` | `#C45C26` | **只给 CTA** |
| `--ok` | `#3F6B4E` | 成功、签到已领 |
| `--gold` | `#D4A017` | 金币 |

## 光
全局**左上主光**：高光浅、阴影深。块、按钮、棋盘同一方向。禁止每屏自定霓虹。

## 字
- 展示：得意黑 `Smiley Sans`（封面、开屏、通关、导航标题）
- 正文：系统黑体（`PingFang SC` / `Microsoft YaHei`）
- 三级：标题 18 / 按钮 15 / 辅助 12。大标题（封面、通关）28，开屏可到 44。禁止第三套字体。

## 文案
短、肯定、像玩具说明书。禁止「个人版」「试玩」「广告位」。看广告换提示是玩法，可以说「看完拿提示」，不要写成后台占位。

## 禁止
蜜桃首页、紫顶栏、绿牌桌、白通关卡并行；1px 白边当块轮廓；振荡器当正式音效；CSS 纯色框冒充木纹（本批只锁色，贴图在 T10）。
