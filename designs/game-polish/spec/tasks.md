# 任务 — 拼个帅哥美女 · 小游戏成色

默认**写完本文件即停**，等用户明确说「开始实现」。一次只做一项；顺序不可跳：先 W0 token，再外壳，再物体，再时间，再内容，再收口。

资产约定：新贴图放 `assets/ui/`（木纹、纸噪、斜面），新音效放 `assets/sfx/`（短 WAV/OGG），文件名小写短横线。

---

## W0 美术宪法

- [x] T0 锁定视觉世界并写入 CSS 变量  
  DoD：`css/app.css` 的 `:root` 含桌面/纸/墨/强调/成功、半径、阴影层级、主光方向注释；删掉或废弃互斥的旧主题色（蜜桃首页、紫顶栏、绿牌桌不再作为独立世界）。短注释写在 `designs/game-polish/spec/art-bible.md`（一页：材质、灯光、文案语气、禁止清单）。

- [x] T1 字体与字号阶梯  
  DoD：展示字只用得意黑；正文系统字体；标题/按钮/辅助信息三级字号写死；任意新界面不得再引入第三字体。

- [x] T2 文案去网页化  
  DoD：全库检索无「个人版」「试玩」「广告位」；开屏/首页/我的语气像游戏（短、肯定），不像后台。

## W1 全屏同一世界

- [ ] T3 开屏改成标题序列  
  DoD：无假广告条；主标题+唯一「开拼」；可有 1.2s 内块合拢/静帧，可跳过；加载时不白屏。

- [ ] T4 首页改成一张封面 + 一颗 CTA  
  DoD：不再像分类运营页；次要入口（图库/我的）弱化；封面与今日推荐同一画框材质。

- [ ] T5 图库：大图、少分类、统一画框  
  DoD：缩略图铺满画框、间距 8px 网格；分类 chip 不超过主+更多；本地项说明「只在这台设备玩，不上传」。

- [ ] T6 「我的」改成暂停室  
  DoD：金币、提示、音效/音乐、关于；布局与首页同世界；不是表单设置页。

- [ ] T7 底栏与顶栏  
  DoD：图标线宽/激活色来自 token；对局中顶栏不再使用与外壳冲突的紫色条。

---

## W4 对局 HUD 减法

- [ ] T8 对局只留棋盘、托盘、一行状态、一个菜单  
  DoD：对局中不出现钱包余额常驻；提示/重开/音效/放弃进入菜单；进度为「n/N」或六点，不占第二行工具条。

- [ ] T9 裁定与提示反馈  
  DoD：正确靠近为磁吸而非闪框；错放短拒+声后消失；无常驻红框、无横幅「判定中」。

---

## W2 棋盘材质

- [ ] T10 桌面与棋盘贴图  
  DoD：可视区域能辨认木纹（或用户改口后的毡）；内倒角/画框阴影；不是纯色 div + 粗 CSS border 冒充。

- [ ] T11 方形浅刻线 + 异形无网格  
  DoD：方形关有极弱刻线或齿缝引导；异形关无网格（保持现状规则）；幽灵图为板上淡印，亮度/对比写死，不闪。

---

## W3 拼图块材质

- [ ] T12 方形块：斜面、厚度、去白边  
  DoD：左上高光、右下厚度影；主轮廓不是 1px 白边；托盘中与棋盘上光照方向一致。

- [ ] T13 异形块：同一套光照，锁定后齐平  
  DoD：`clip-path` 齿仍在；高光沿边缘（可用 inset shadow / 叠加贴图）；锁定后与邻居齐平，浮起感只存在于拖拽中。

- [ ] T14 锁定块 vs 未锁定块  
  DoD：预锁角（1/2/3）看起来像已嵌进板里；未锁定在托盘有厚度；两者不会被误认成同一层贴纸。

---

## W5 手感动效

- [ ] T15 发牌  
  DoD：开局块进入托盘有错开 30–50ms 的短动画；可跳过重复关。

- [ ] T16 拾起 / 拖拽 / 落下  
  DoD：抬起位移+影变长；拖拽中块高于一切；落下 80–120ms ease；不穿帮到顶栏下。

- [ ] T17 磁吸与咬合  
  DoD：进入吸附半径有向槽位的缓动；锁定瞬间短顿；可关动画的无障碍不做，本产品不做无障碍专项。

- [ ] T18 错放弹回  
  DoD：弹回托盘或原位，带过冲；无 JS 报错；10×10 仍可用。

- [ ] T19 碎裂与屏间转场  
  DoD：通关碎裂保留并接到新结果卡；首页↔对局↔结果至少有淡入或板面推移，禁止硬切白闪。

- [ ] T20 连击与微粒  
  DoD：连击有可感知强化（已有 SFX 接动画）；锁定微粒限流（同时≤8），低端机可关粒子但保留位移。

## W6 拟音

- [ ] T21 接入短采样总线  
  DoD：`js/sfx.js` 播放拾起/放下/咬合/错放/通关采样；master + 压缩器可留；无文件时静音而不是公开振荡器方案。

- [ ] T22 手势解锁与双开关  
  DoD：每次 pointerdown 尝试 resume；`sfxOn` / `musicOn` 分键；我的页可测「现在有没有声」。

- [ ] T23 可选 BGM  
  DoD：循环乐默认关、音量低于音效；进对局才响，回首页可淡出。用户若否决本项则删文件并勾掉，不留半残循环。
