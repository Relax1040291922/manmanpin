# 原则卡 — 拼个帅哥美女 · 小游戏成色

## 对齐产品
- 硬约束：成人休闲拼图（非色情）；无内购；金币稀缺；广告换提示是主变现；中文界面；本地相册只玩不上传。
- 本轮只做：把现有 HTML 原型做成**可对外宣称的一款小游戏**——视觉世界、实体拼图手感、音画节奏、内容成色、全屏一致，验收按商店里的休闲拼图，不按「H5 试玩」。
- 明确不做：换引擎/换栈；独立第二款「百科全拼」；儿童向改版；内购；后端账号；为赶工砍掉材质/动效/音效/内容筛选。

## 技术约束
- 沿用 `manmanpin`：Vanilla HTML / CSS / JS（`Puzzle` / `Sfx` / `Economy` / `Store`），GitHub Pages 静态发布。
- 资源走本地 `assets/`、`fonts/`、`css/`、`js/`；缓存用 `?v=`，不引入打包器除非规格另开一轮。
- `localStorage` 键 `manmanpin_v1` 兼容升级；阶段进度、金币、音效开关不得无故清空。
- 材质与音效用**真实贴图/短采样**优先，CSS 渐变与振荡器只作占位，不得作为终态。

## 质量底线
- 成功标准：手机上 30 秒内能感到「这是一盒桌上的拼图」，而不是「一个带拖拽的网页」。
- 全屏同一世界：开屏 / 首页 / 图库 / 对局 / 通关 / 我的，共用一套色、字、材质、动效语法。
- 对局 60fps 目标：中端安卓与 iPhone 上 4×4～8×8 拖拽不掉帧；10×10 允许略降粒子，不允许卡死。
- 空态、加载、失败、首次手势开声，都要设计，不能空白或浏览器默认。

## 禁止
- 用「反正是 HTML」降低材质、动效、音效、图集成色。
- 只改三处最显眼的点交差（最短路径）。
- 继续混用蜜桃首页 / 紫顶栏 / 绿牌桌 / 白通关卡。
- 拼图块靠白描边、虚线槽、扁平 `clip-path` 冒充成品。
- 文案残留「个人版」「试玩」「广告位」。
- 无关重构、换框架、顺手做百科/新品类 App。
